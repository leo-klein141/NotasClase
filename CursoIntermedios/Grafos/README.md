# GRAFOS: Visto desde la programación comppetitiva


El objetivo de esta sección es el entender las partes fundamentales de un grafo. Cómo lo dice el título, nuestro objetivo no es ahondar en los teoremas o propiedades de los grafos,
si no dar herramientas para poder entenderlos y poder usarlos. Por lo que nos delimitamos a ver estos temas dentro de este nivel:

- Definiciones y conceptos de grafos.
- Representación de grafos
- Búsqueda en amplitud y profundidad (BFS/DFS)
    -  Conjuntos Disjuntos
    -  Componentes Fuertemente Conexas
    -  Orden Topólogico
    -  Técnica de Flood-Fill
    -  Otros
-  Caminos Minimos (Una sola fuente):
    - Distancias positivas (Dijkstra)
    - Distancias arbitrarias (Bellman-Ford)
- Todos los posibles caminos minimos:
    - Floyd-Warshall
- Árboles de expansión Mínima
- Primer Antecesor en común (LCA)
- Camino Euleriano
